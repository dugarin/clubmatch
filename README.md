# КлубМатч (clubmatch)

Сервис профессионального подбора участников сообщества.
Анкеты участников, рекомендации, поиск людей под запрос — на базе Telegram Mini App.

## Заголовок спецификации

| Поле | Значение |
|---|---|
| Фича | «КлубМатч» — сервис профессионального подбора участников сообщества (рабочее название) |
| Статус | spec 1.1 (2026-10-30: UC-1 + шаг запуска бота; NFR-12 — уведомления о заявке при наличии связки с ботом); условная приёмка FR-8/AC-4 — до спайка `tg://user?id`, см. [docs/spikes/tg-user-link.md](docs/spikes/tg-user-link.md). Архитектура (фаза 2) утверждена: [docs/architecture](docs/architecture) |
| Дата | 2026-10-29 |
| Источник | Устное описание заказчика: «Нечто с карточками участников, который может находить людей под запрос (например, нужно разобраться с кафкой или внедрением sdd). Должны быть анкеты участников, рекомендации, онбординг» |
| Владелец | заказчик (без имени — решение Q4, 2026-10-29) |
