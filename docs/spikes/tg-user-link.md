# Спайк: реализуемость `tg://user?id=...` как контакта при скрытом username

Контекст: Q10, FR-8, UC-4 E1, AC-4. Проверялось предположение, что при отсутствии
публичного username контактом может быть user id со ссылкой `tg://user?id=<id>`.

## Итог исследования

**Статус: завершён 2026-10-31 по официальной документации Telegram. Ручная проверка
на устройствах не выполнялась и не требуется для вывода об ограничениях формата.**

**Результат: `tg://user?id` нельзя использовать как универсальный контакт в Mini App.**
Это не отдельная deep-link к произвольному пользователю, а абстракция Bot API для
inline-упоминаний и кнопок профиля. Работоспособность зависит от контекста ссылки,
приватности и предыдущего взаимодействия пользователя с ботом.

### Подтверждения из официальных источников

1. В разделе [ID links официального описания deep links](https://core.telegram.org/api/links#id-links)
   указано: `tg://user?id=<id>` лишь упрощает создание
   `inputMessageEntityMentionName` и `inputKeyboardButtonUserProfile` через Bot API;
   обычные клиенты должны игнорировать такие ID-ссылки как самостоятельные deep links.
2. В [Bot API — Formatting options](https://core.telegram.org/bots/api#formatting-options)
   указано, что ссылка работает только внутри inline-ссылки или inline-кнопки;
   в обычном тексте сообщения она не работает. Если упомянутый пользователь не состоит
   в чате, работа гарантируется только после его обращения к боту в личке или callback
   query и при отсутствии ограничения Forwarded Messages privacy для бота.
3. Официальные [Public username links](https://core.telegram.org/api/links#public-username-links)
   используют `t.me/<username>` и `tg://resolve?domain=<username>`, то есть требуют
   публичный username.
4. Официальная альтернатива для профиля без username —
   [временная ссылка `t.me/contact/<token>`](https://core.telegram.org/api/links#temporary-profile-links).
   Токен создаётся через MTProto `contacts.exportContactToken` и имеет срок действия;
   это не постоянная ссылка, которую backend на Bot API может сформировать по user id.
5. `https://t.me/user?id=...` и `tg://openmessage?user_id=...` не входят в перечень
   документированных ссылок для открытия профиля по ID и не принимаются как решение.

## Решение Q10 для MVP

- При наличии публичного username передаются `@username` и ссылка
  `https://t.me/<username>`.
- При отсутствии публичного username передаются числовой Telegram user id и пояснение,
  что прямой переход к чату по ID не гарантирован. Ссылка `tg://user?id` в Mini App
  не используется.
- AC-4 проверяет повторную выдачу доступных контактных данных в Mini App и не требует
  гарантированного открытия чата по числовому ID.

Остаточное ограничение: при отсутствии username доступный идентификатор не всегда
позволяет начать чат напрямую. Это осознанное ограничение MVP, а не непроверенная
техническая гипотеза.
