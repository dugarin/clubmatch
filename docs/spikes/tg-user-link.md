# Спайк: реализуемость `tg://user?id=...` как контакта при скрытом username

Контекст: Q10, FR-8, UC-4 E1, AC-4. Если у участника скрыт username, спецификация
предполагает контакт = user id + ссылка `tg://user?id=<id>` `[непроверено]`.
До результата спайка FR-8 не считается приёмочным (AC-4 условный).

Исполняется вручную в реальном Telegram (владелец/разработчик). Результат —
в `docs/requirements/08-approval-form.md`, блок 3.

## Предусловия

- Два тестовых аккаунта Telegram: A (без публичного username или со скрытым
  в настройках приватности), B (исполнитель).
- Известен user id аккаунта A (например, через бота `@userinfobot` или Bot API `getUpdates`).
- Клиенты: Telegram iOS, Android, Desktop — проверка на каждом доступном.

## Шаги проверки

| # | Шаг | Ожидаемое при успехе | Факт |
|---|---|---|---|
| 1 | B открывает ссылку `tg://user?id=<id A>` (вставить в «Избранное» и перейти) | Открывается чат/профиль A | |
| 2 | То же при отсутствии у A публичного username | Работает как в шаге 1 | |
| 3 | То же при запрете «Кто может найти меня» / ограничениях приватности A | Зафиксировать поведение (блок?) | |
| 4 | Повторить шаги 1–3 на другом клиенте (iOS/Android/Desktop) | Одинаковое поведение | |
| 5 | Проверить вариант без предварительного контакта (A и B не переписывались, нет общих групп) | Зафиксировать: открывается ли чат | |
| 6 | Альтернатива: deep-link вида `https://t.me/user?id=...` или `tg://openmessage?user_id=...` | Зафиксировать работоспособность | |

## Критерии результата

- **Успех**: ссылка открывает чат/профиль на всех целевых клиентах без предварительного
  контакта → FR-8 приёмочен, AC-4 становится безусловным, метка `[непроверено]` снимается.
- **Частичный успех**: работает не везде/не всегда → зафиксировать ограничения,
  скорректировать FR-8 (например, контакт = user id в текстовом виде + инструкция).
- **Неуспех**: ссылка не работает → пересмотр Q10: варианты — обязательный username
  при онбординге, телефон (по согласию), иной канал связи.

## Риски/ограничения

- Поведение deep-link не документировано официально и может меняться между версиями
  клиентов `[непроверено]`.
- Проверка на эмуляторе недостаточна — нужны реальные клиенты.
