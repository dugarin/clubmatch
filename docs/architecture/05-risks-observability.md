| # | Риск | Severity | Источник | Митигация |
|---|---|---|---|---|
| R1 | Утечка скрытых полей через новый эндпоинт, обходящий политику видимости | high | ADR-004 | Единый сериализатор; контрактные тесты AC-7 на каждый эндпоинт с данными анкеты; правило ревью |

## Observability

**Логи** (структурированные JSON, `request_id` сквозной):
- API: метод, путь, статус, latency, telegram_user_id (хэш `[предположение]` — ПДн в логах минимизировать), код ошибки валидации.
- Worker: событие outbox (id, type, попытка, результат, код ошибки Bot API).
- Журналы доменные (раскрытие контакта, решения модератора) — в БД, 1 год (NFR-10); в операционные логи не дублировать содержимое контактов.

**Метрики**:
| Метрика | Требование | Алерт |
|---|---|---|
| `http_latency_p95{endpoint}` | NFR-1…NFR-3 (загрузка ≤3с, поиск ≤5с, колода ≤1с) | p95 поиск > 4 с, 15 мин |
| `notification_lag_seconds` | NFR-12 (≤1 мин) | p95 > 60 с |
| `outbox_depth`, `outbox_oldest_age` | NFR-12 | age > 10 мин |
| `initdata_validation_failures` | безопасность | всплеск > baseline |
| `db_up`, свободное место, размер журналов | NFR-6, NFR-10 | недоступность > 5 мин |

**Трейсинг**: на MVP — корреляция по `request_id` без OTel-коллектора `[предположение: OTel — non-goal MVP, добавить при росте]`.

**Health**: `/healthz` (процесс), `/readyz` (БД-доступность) для API; liveness worker — heartbeat-запись.
