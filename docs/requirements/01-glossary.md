# 01. Глоссарий

| Термин | Определение |
|---|---|
| Сообщество `[NEW]` | Группа людей, объединённая общим профессиональным интересом; на старте — закрытая |
| Кандидат `[NEW]` | Человек, претендующий на вступление в сообщество: получил приглашение или подал заявку, но ещё не прошёл онбординг |
| Участник | Кандидат, прошедший онбординг и имеющий анкету в сервисе |
| Анкета | Набор структурированных сведений об участнике: навыки, проекты, профессиональные и личные интересы, локация, формат встречи (состав полей — в [03](03-functional-requirements.md)) |
| Карточка | Представление анкеты участника в интерфейсе подбора |
| Запрос | Формулировка потребности участника (напр., «разобраться с кафкой»), по которой система возвращает карточки в поиске ([FR-10](03-functional-requirements.md)); полем анкеты не является |
| Рекомендация | Карточка, предложенная участнику системой без явного запроса |
| Колода карточек `[NEW]` | Последовательность рекомендаций, показываемая участнику для оценки ([FR-5](03-functional-requirements.md)); не является лентой постов (non-goal в [02](02-task-description.md)) |
| Оценка `[NEW]` | Действие участника по отношению к карточке: «интересно» или «не интересно» ([FR-6](03-functional-requirements.md)); оценка из колоды и из поиска — одна сущность ([FR-12](03-functional-requirements.md)) |
| Матч `[NEW]` | Состояние взаимного интереса двух участников, после которого открывается контакт |
| Telegram-контакт `[NEW]` | Идентификатор участника в Telegram для связи: username; при скрытом username — user id и ссылка `tg://user?id=...` (реализуемость `[непроверено]`, Q10) |
| Онбординг | Процесс первого входа: создание анкеты с обязательными полями ([FR-1](03-functional-requirements.md), [FR-2](03-functional-requirements.md)) |
| Модератор `[NEW]` | Лицо, контролирующее вступление участников и качество анкет |
| Справочник тегов `[NEW]` | Перечень нормализованных значений для навыков и интересов; пополняется участниками |
