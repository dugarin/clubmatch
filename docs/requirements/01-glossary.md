# 01. Глоссарий

| Термин | Определение |
|---|---|
| Сообщество | Группа людей, объединённая общим профессиональным интересом; на старте — закрытая |
| Участник | Человек, прошедший онбординг и имеющий анкету в сервисе |
| Анкета | Набор структурированных сведений об участнике: навыки, опыт, интересы, запросы |
| Карточка | Представление анкеты участника в интерфейсе подбора |
| Запрос | Формулировка потребности участника (напр., «разобраться с кафкой»), по которой подбираются карточки |
| Рекомендация | Карточка, предложенная участнику системой без явного запроса |
| Матч | Состояние взаимного интереса двух участников, после которого открывается контакт |
| Онбординг | Процесс первого входа: заполнение анкеты и знакомство с сервисом |
| Модератор | Лицо, контролирующее вступление участников и качество анкет |
| Справочник тегов | Перечень нормализованных значений для навыков и интересов; пополняется участниками |
