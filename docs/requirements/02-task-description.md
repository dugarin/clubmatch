# 02. Описание задачи

## Проблема

В профессиональном сообществе участники не знают, кто обладает нужной экспертизой;
найти человека под конкретную задачу (разобраться с технологией, внедрить практику) затруднительно.

## Решение

Сервис в виде Telegram Mini App: участник проходит онбординг и заполняет анкету;
система позволяет искать людей по текстовому запросу и просматривать колоду рекомендованных
карточек с оценкой «интересно» / «не интересно»; при взаимном интересе (матч) открывается контакт.

## Контекст

- Платформа: Telegram (Mini App; бот — только для уведомлений, NFR-7).
- Сообщество на старте закрытое, позже — открытое (отдельный этап).
- Заказчик выделяет три обязательных элемента: анкеты, рекомендации, онбординг.
- Персональные данные участников передаются через инфраструктуру Telegram (аутентификация, уведомления, контакт при матче) — это часть модели сервиса (NFR-10, Q22) `[предположение]`.

## Ограничения

- Источник требований — только устное описание заказчика; детали сформулированы
  как предложение и требуют утверждения заказчиком (см. [07-open-questions](07-open-questions.md)).

## Не цели (non-goals)

- Не соцсеть: нет ленты постов, комментариев.
- Не фриланс-биржа: нет заказов, оплат, сделок.
- Не романтические знакомства: только профессиональный нетворкинг.
- Масштабирование на открытую аудиторию — отдельный этап, в MVP не входит.
