# 05. Сценарии использования (UC)

Акторы: участник, модератор, бот (система). Термины — по [глоссарию](01-glossary.md).

## UC-1. Онбординг нового участника

**Покрывает:** FR-1, FR-2, FR-4, FR-13, NFR-7.
**Предусловия:** пользователь получил приглашение/одобрен модератором; открыл Mini App.

**Основной поток:**
1. Система аутентифицирует пользователя через Telegram.
2. Система показывает форму анкеты с подсказками-шагами.
3. Пользователь заполняет обязательные поля (имя, ≥1 навык, формат встречи); навыки вводит вручную или выбирает из тегов с автодополнением.
4. Пользователь завершает онбординг → анкета сохранена, участник попадает в ленту рекомендаций.

**Альтернативы:**
- 3а. Пользователь создаёт новый тег — тег добавляется в справочник.

**Ошибки:**
- E1. Не заполнены обязательные поля → завершение заблокировано, поля подсвечены.
- E2. Пользователь без доступа → сообщение о закрытом сообществе и форма заявки.

## UC-2. Редактирование анкеты

**Покрывает:** FR-3, FR-4.

**Основной поток:** участник открывает «Моя анкета» → меняет поля → сохраняет → обновлённая анкета участвует в поиске и рекомендациях.

## UC-3. Лента рекомендаций и свайпы

**Покрывает:** FR-5, FR-6, FR-9.

**Основной поток:** система показывает карточку → участник свайпает «интересно»/«не интересно» → система фиксирует оценку и показывает следующую карточку; оценённые карточки повторно не показываются.

**Альтернативы:**
- 2а. «Интересно» при уже имеющемся встречном лайке → переход в UC-4.

**Ошибки:**
- E1. Рекомендации исчерпаны → заглушка «пока всё, возвращайтесь позже».

## UC-4. Матч и выход на связь

**Акторы:** два участника, бот.
**Покрывает:** FR-7, FR-8, FR-14, NFR-12.

**Основной поток:** система фиксирует взаимный интерес → создаёт матч → бот отправляет обоим уведомление с Telegram-контактом второй стороны → участники общаются в личке Telegram.

**Ошибки:**
- E1. У участника скрыт username → система передаёт ссылку `tg://user?id=...` (требует проверки реализуемости).

## UC-5. Поиск людей под запрос

**Покрывает:** FR-10, FR-11, FR-12, NFR-2.

**Основной поток:** участник вводит запрос («нужно разобраться с кафкой») → система возвращает ранжированный список карточек → участник применяет фильтры (локация, формат встречи) → отмечает карточку «интересно» → при взаимности UC-4.

**Альтернативы:**
- 3а. Пустой результат → предложение смягчить фильтры или подобные запросы.

## UC-6. Вступление в закрытое сообщество

**Акторы:** кандидат, модератор.
**Покрывает:** FR-13.

**Основной поток:** кандидат открывает бота → подаёт заявку → модератор одобряет/отклоняет → при одобрении кандидат проходит UC-1.

**Альтернативы:**
- 2а. Вступление по ссылке-приглашению без модерации (открытый вопрос Q1).
