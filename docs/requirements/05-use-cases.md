# 05. Сценарии использования (UC)

Акторы: кандидат, участник, модератор, бот (система). Термины — по [глоссарию](01-glossary.md).

## UC-1. Онбординг нового участника

**Акторы:** кандидат.
**Покрывает:** FR-1, FR-2, FR-4, FR-13, FR-16, NFR-7.
**Предусловия:** кандидат получил приглашение или одобрен модератором (FR-13); открыл Mini App.

**Основной поток:**
1. Система аутентифицирует кандидата через Telegram.
2. Система показывает форму анкеты с подсказками-шагами.
3. Кандидат заполняет обязательные поля (имя, ≥1 навык, формат встречи); навыки вводит вручную или выбирает из тегов с автодополнением.
4. Кандидат подтверждает согласие на обработку персональных данных и раскрытие контакта при взаимной оценке «интересно» (FR-16).
5. Кандидат завершает онбординг → анкета сохранена, кандидат становится участником и попадает в колоду карточек.

**Альтернативы:**
- 3а. Кандидат создаёт новый тег — тег добавляется в справочник.

**Ошибки:**
- E1. Не заполнены обязательные поля → завершение заблокировано, поля подсвечены.
- E2. Кандидат без приглашения или одобрения → сообщение о закрытом сообществе и форма заявки в Mini App (FR-13).
- E3. Согласие не подтверждено → завершение онбординга заблокировано (FR-16).

## UC-2. Редактирование анкеты

**Покрывает:** FR-3, FR-4.

**Основной поток:** участник открывает «Моя анкета» → меняет поля → сохраняет → обновлённая анкета участвует в поиске и рекомендациях.

**Ошибки:**
- E1. Попытка сохранить анкету с пустым обязательным полем (имя, ни одного навыка) → сохранение заблокировано, поле подсвечено (FR-2, FR-3).

## UC-3. Колода карточек и оценки

**Покрывает:** FR-5, FR-6, FR-9.

**Основной поток:** система показывает карточку → участник оценивает её («интересно» / «не интересно», FR-6) → система фиксирует оценку и показывает следующую карточку; оценённые карточки повторно не показываются.

**Альтернативы:**
- 2а. Оценка «интересно» при уже имеющейся встречной оценке «интересно» → переход в UC-4.

**Ошибки:**
- E1. Рекомендации исчерпаны → заглушка «карточки закончились; новые появятся с новыми участниками» `[предположение]` (Q16).

## UC-4. Матч и выход на связь

**Акторы:** два участника, бот.
**Покрывает:** FR-7, FR-8, FR-14, NFR-12.

**Основной поток:** система фиксирует взаимный интерес → создаёт матч → контакт второй стороны появляется у обоих в разделе «Матчи» в Mini App → бот отправляет уведомление с Telegram-контактом → участники общаются в личке Telegram.

**Альтернативы:**
- 4а. Участник повторно открывает раздел «Матчи» — контакт второй стороны доступен без повторного уведомления.

**Ошибки:**
- E1. У участника скрыт username → система передаёт user id и ссылку `tg://user?id=...` (реализуемость `[непроверено]`, Q10).
- E2. Уведомление бота не доставлено (бот заблокирован, сбой) → матч и контакт сохраняются в Mini App; уведомление повторяется при первой возможности `[предположение]`.

## UC-5. Поиск людей под запрос

**Покрывает:** FR-10, FR-11, FR-12, NFR-2.

**Основной поток:** участник вводит запрос («нужно разобраться с кафкой») → система возвращает ранжированный список карточек → участник применяет фильтры (локация, формат встречи) → оценивает карточку «интересно» → при взаимности UC-4.

**Альтернативы:**
- 2а. Карточка уже оценена → показывается с меткой текущей оценки; оценку можно изменить (FR-9, FR-12).
- 3а. Пустой результат → предложение смягчить фильтры или подобные запросы.

## UC-6. Вступление в закрытое сообщество

**Акторы:** кандидат, модератор.
**Покрывает:** FR-13, FR-15.

**Основной поток:** кандидат открывает Mini App → видит форму заявки (UC-1 E2) → подаёт заявку → модератор одобряет или отклоняет её (FR-15) → кандидат получает уведомление бота (NFR-12) → при одобрении кандидат проходит UC-1.

**Альтернативы:**
- 2а. Вступление по ссылке-приглашению без модерации: ссылку создаёт модератор, срок действия 7 дней, одноразовая `[предположение]` (Q1).

**Ошибки:**
- E1. Заявка отклонена → кандидат получает уведомление бота; онбординг недоступен; повторная подача заявки разрешена `[предположение]` (Q21).

## UC-7. Удаление анкеты

**Акторы:** участник.
**Покрывает:** FR-17.

**Основной поток:** участник открывает «Моя анкета» → выбирает удаление → подтверждает → анкета, оценки и матчи удаляются; в списках матчей второй стороны контакт помечается недоступным.
